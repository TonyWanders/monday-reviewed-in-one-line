A program that writes one funny one-line review of Monday to
`/output/entry.txt`, for the make.fun competition
[Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

Run it with Python 3:

```
python3 main.py
```

It writes the review below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The review is 111 characters, inside the 1 to 200 gate, a
single line with no title and no explanation.

## The review

```
My Monday earned one star: 47 unread emails, a meeting about the meeting, and a Quick Sync that synced nothing.
```
